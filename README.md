Personal portfolio and services website for **Phillip Pantaleano**, a Senior UI/UX Developer specializing in AI, Angular, design systems, and modern front-end architecture.

Built with Angular and designed with a dark, space-inspired aesthetic.

## Features

- Responsive portfolio website
- Services, Portfolio, and Contact pages
- Contact form powered by Formspree
- Modern dark UI with Tailwind CSS
- Angular Material form components
- Optimized for deployment on IONOS Deploy Now

## Tech Stack

- **Framework:** Angular 22
- **Styling:** Tailwind CSS + Angular Material
- **Forms:** Formspree
- **Language:** TypeScript
- **Hosting:** IONOS Deploy Now

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- Angular CLI
